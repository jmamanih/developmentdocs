# ADOBE ILLUSTRATOR

![Illustrator](images/Illustrator_icon.png)
Adobe Illustrator, es la aplicación de gráficos vectoriales estándar del sector que te permite crear logotipos, iconos, dibujos, tipografías e ilustraciones complejas para cualquier medio


## Operaciones Básicas

Comandos importantes

    Escalar con proporción              Shift + Mouse
    Herramienta Selección directa       A
    Herramienta Mesa de Trabajo         Shift + O
    Acercar                             Cmd +
    Alejar                              Cmd -
    Duplicar objeto                     Ctrl+C, Ctrl+F

## La herramienta Pluma

    P               Activar Pluma
    Alt             Cambiar dirección
    C               Cortar
    Esc             Terminar
    A               Editar
    A, Ctrl + J     Unir puntos
    Cmd+Shift+F9    Buscatrazos, dividir


### Dibujar con la pluma

    Importar imagen
    Bajar opacidad                  Menu Ventana, Transparencia
    Bloquear capa de la imagen      Menu Objeto, Bloquear, Selección
    Crear una capa nueva       
    Seleccionar herramienta pluma   P
    Desactivar relleno              X
    Dibujar lineas sobre la imagen
    Descativar guias inteligentes   Menu Ver, Guias inteligentes
    Convertir lineas en curvas      Herramienta punto de ancla
    Retocar con las guias
    Ordenar objetos                 Menu contextual, Ordenar
    Rellenar colores                Herramienta Relleno


## Vectorizar una Imagen

*Primera Forma*

* Crear una mesa de trabajo en cm
* Arrastrar imagen a la mesa de trabajo
* Elegir Herramienta Selección directa 
* Menu Ventana, Calco de Imagen, Por Defecto, Expandir
* Ctrl + Y, suprimir

*Segunda Forma*
* Trazar sobre la imagen la herramienta pluma
