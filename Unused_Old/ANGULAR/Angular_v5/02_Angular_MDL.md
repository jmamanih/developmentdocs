
# ANGULAR MATERIAL DESIGN LITE (MDL)
## Install MDL

* [Material Design Lite](https://getmdl.io/)
* [Material Design Lite Components Extension](http://mdl.gixx-web.com/)
* [Documentation Material Design Lite](https://desolate-fjord-7338.herokuapp.com/)

Init bower

```sh
cd project_angular
bower init
```

Install MDL

```sh
bower install angular-material-design-lite --save
```

Install MDL Icons

```sh
bower install material-design-icons --save
```
