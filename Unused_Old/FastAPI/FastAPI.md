# FASTAPI

![Logo FastAPI](images/fastapi.png)

FastAPI es un framework web moderno y rápido para construir APIs en Python, diseñado para ser fácil de usar, eficiente y altamente performante. Se destaca por aprovechar las capacidades de Python tipo asíncrono (async) y el tipado estático, lo que lo hace ideal para desarrollar aplicaciones que requieren alta concurrencia o manejo eficiente de recursos.
