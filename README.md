```
Por: Juan F. Mamani H.
```

Mediante este manual se pretende orientar al lector en el uso de las herramientas tecnológicas en el ámbito de la informática, escencialmente en el área del desarrollo de aplicaciones como ser aplicaciones Web, aplicaciones de escritorio y aplicaciones móviles.

Tambien se concentra conceptos fundamentales de las tecnologias de información y guías prácticas de instalación.

Algunas instrucciones o comentarios están en inglés porque son más entendibles y muy inttuitivos.

**TECNOLOGÍA INFORMÁTICA (IT)**

Es el estudio, diseño, desarrollo, puesta en producción, ayuda o gerencia de los sistemas informáticos computarizados, particularmente usos del Software y Hardware.
