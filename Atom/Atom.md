# Customize the ATOM Editor

## Intall Themes

Install

```
Open Atom, Preferences, Install, Select THEMES Button, search: theme_name
```

Install Theme Material-UI

```
apm install atom-material-ui

```

Choose a Theme

```
Open Atom, Preferences, themes, Select in UI Theme: Atom Material, and Syntax Theme: Atom Dark
```

## Install Package

Install

```
Open Atom, Preferences, Install, Select PACKAGE Button, search: package_name
```

Packages
* emmet, Usage: ! + Crtl+E
* color-picker
* file-icons
* mini-map
* template-generator
* pigmments
* markdown-scroll-sync
* activate-power-mode
* merge-conflicts
* linter
* fonts

## Update Packages

```
Open Atom, Preferences, Updates, UPDATE ALL
```
