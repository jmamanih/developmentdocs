## Create character 3D person

* [Register in Autodesk character Generator for download models](https://www.autodesk.com/education/free-software/character-generator)
	GET ACCESS, Character Generator, SIGN IN
* Custom Person, Finish, Asign name
* Optimize chacarter for Unity, Select Character Generate
	Poly Resolution: Low
	Textures: Clotes and Normal Map
	Geometry: Triangles
	Facial Expressions: none
	Generate: Unity (.fbx)
	Generate Button
* Download Generated Characters

* [Open second time for edit characters](https://charactergenerator.autodesk.com/)

## Create Project Unity

* Open Unity, Create Project 3D, select assets: Materials
* Create in assets folder Characters, drag and drop character generate, fix now
  Open chacarer, tab Rig, Animation type, select : humanoid, Apply
* Configure Character
  - Select character, Rig, configure
  - Mapping: Automap
  - Pose: Enforce T-Pose
  - Apply, Done
