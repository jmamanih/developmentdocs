# WARP TERMINAL

Warp es una terminal moderna basada en Rust, diseñada para mejorar la experiencia del desarrollador con una interfaz gráfica enriquecida, soporte para IA y múltiples funcionalidades integradas. 

## Comandos mas relevantes

    Cmd + ,                     // Panel de configuración
    Cmd + P                     // Paleta de Comandos
    Cmd + Shift + D             // Dividir pantalla verticalmente
    Cmd + Shift + E             // Dividir pantalla horizontalmente
    Cmd + Option + Flechas      // Moverse entre paneles
    Cmd + Espaciadora           // Panel AI
                                   Usar # seguido de la pregunta para invocar Warp AI directamente en la terminal. 
    Cmd + Shift + T             // Nueva Pestaña
    Cmd + Shift + W             // Cerrar Pestaña Actual
    Cmd + ↑ / ↓                 // Navegar entre bloques de comandos
    Cmd + Shift + F             // Buscar texto
    Cmd + Shift + K             // Limpiar pantalla
    Cmd + C                     // Copiar
    Cmd + V                     // Pegar
    Cmd + Shift + P             // Buscar comando
                                   Para elegir un Tema, escribir Theme -> Open Theme Picker y seleccionar el tema
    Cmd + 1                     // Ir a una pestaña especifica en este caso 1
                                   Se usa 9 para ir a la ultima pestaña 

**Nota:** En windows usar la tecla "Ctrl" en vez de "Cmd" y "Alt" en lugar de "Option"

## Configurar los Shorcuts (Atajos de Teclado)

    Cmd + Shift + P
    Escribir: shortcuts, elegir Open Settings: Keyboard Shortcuts

    Increase Font Size          Cmd + 
    Decrease Font Size          Cmd -
    Active Next Tab             Ctrl PgUp
    Active Previus Tab          Ctrl PgDown
