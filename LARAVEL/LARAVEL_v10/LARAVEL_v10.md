# LARAVEL v10

## Instalación

1. Instalar Laravel HERD
2. Instalar Base de Datos MYSQL

## Verificar la instalacion de prerequisitos

```sh
php --version
composer --version
laravel --version
mysql --version
code .
```

## Crear un proyecto o aplicación Laravel

Existen dos formas de crear aplicaciones Laravel

1. Actualizar nvm y node
```sh
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.38.0/install.sh | bash
```
```sh
nvm install node
```
2. Ingresar al directorio de Sitios
```sh
cd Sites
```
3. Actualizar nvm y node
```sh
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.38.0/install.sh | bash
```
```sh
nvm install node
npm install -g npm
```
4. Crean proyecto mediante Composer
```sh
composer require laravel/laravel nombreApp
```
5. Crear proyecto mediante Laravel
```sh
laravel new nombreApp
```

Ejemplo:

```sh
laravel new primerapp --git

   Would you like to install a starter kit?
   Laravel Breeze

   Which Breeze stack would you like to install?
   React with Inertia
   
   Would you like any optional features?
   Inertia SSR

   Which testing framework do you prefer?
   PHPUnit

   Which database will your application use?
   MySQL 
```
Para ejecutar la app, escribir en la barra de direcciones del navegador:
```sh
primerapp.test
```
